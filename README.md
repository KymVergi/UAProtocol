# 🛸 UAP Protocol

Dynamic Stability Mechanism on Uniswap V4

## Quick Start

```bash
npm install
cp .env.example .env
# Edit .env with your contract addresses
npm run dev
```

## Features

- Large vintage CRT monitor (90% screen)
- CSS-drawn (no SVG)
- Tabs: App, Whitepaper, Technical, Rules, Chronicle
- Scrollable documentation viewer
- Swap interface with demo data

## Configuration

Edit `.env` with deployed contract addresses.

Place GIFs in `/public/gifs/` (optional).
